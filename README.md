# 실습앱 — 나만의 단어장

4주 동안 **앱 하나**를 만듭니다. 매주 버리고 새로 시작하지 않습니다.

이 폴더에는 **회차별 시작 코드**가 들어 있습니다.
지난 주에 못 오셨거나, 내 코드가 어디서부터 꼬였는지 모르겠다면
**그 주차의 `-start` 폴더를 복사해서 거기서부터 이어가면 됩니다.**

---

## 📖 수업 중에는 「따라하기」 문서를 옆에 띄워두세요

빔프로젝터의 코드를 눈으로 따라 치면 시간이 모자랍니다.
**[`따라하기/`](따라하기/) 폴더의 HTML 파일을 다운로드해서 브라우저로 열어두세요.**
에디터 옆에 놓고 보는 용도입니다.

| 기능 | 설명 |
|---|---|
| **코드 복사 버튼** | 코드블록 오른쪽 `복사` 를 누르면 바로 붙여넣을 수 있습니다. 설명용 화살표 주석(`← 이렇게`)은 자동으로 빠집니다 |
| **진도 체크박스** | 체크한 상태가 브라우저에 저장됩니다. 상단 진행바로 지금 어디까지 왔는지 보입니다 |
| **자주 나는 에러** | 그 회차에서 실제로 많이 막히는 지점을 접어두었습니다. 손 들기 전에 먼저 펼쳐보세요 |
| **테마 전환** | 우측 상단 버튼. 화면이 눈부시면 바꾸세요 |

**여는 법 — 둘 중 편한 쪽으로.**

1. **저장소를 통째로 받았다면** (`git clone` 또는 초록색 `Code` → `Download ZIP`)
   → `따라하기/1회차-따라하기.html` 을 **더블클릭**하면 브라우저에서 열립니다.
2. **GitHub 웹에서 보고 있다면**
   → 파일을 연 뒤 우측 상단 **`Download raw file`** (아래 화살표 아이콘)로 내려받아 여세요.

> ⚠️ GitHub 웹 미리보기는 HTML을 **코드 그대로** 보여줍니다. 반드시 **내려받아서** 여세요.
> 인터넷 없이도 열립니다 — 파일 하나에 전부 들어 있습니다.

> 위 표는 4주 전체 지도라고 보시면 됩니다.

## 실행 방법

폴더 하나를 골라서, **그 폴더 안에서** 터미널을 엽니다.

```bash
cd week1-start     # 또는 week2-start
npm install        # 처음 한 번만. 라이브러리를 내려받습니다 (몇 분 걸립니다)
npm run dev        # 개발 서버를 켭니다
```

터미널에 이런 게 뜹니다.

```
  VITE v5.4.x  ready in 412 ms

  ➜  Local:   http://localhost:5173/
```

브라우저에서 **http://localhost:5173** 을 엽니다. 카드가 보이면 성공입니다.

**터미널은 켜둔 채로 두세요.** 끄면 화면이 죽습니다.
파일을 고치고 저장하면 브라우저가 저절로 바뀝니다.
서버를 끌 때는 터미널에서 `Ctrl + C` 입니다.

**2회차부터는 터미널을 두 개** 씁니다 — 검색 데이터가 미니 API 서버(로컬)에서 오기 때문입니다.
`mini-api/` 폴더는 **이미 올라와 있습니다.** 2회차 전에 한 번 띄워보셔도 좋습니다.

```bash
# 터미널 1 — 미니 API 서버 (수업 내내 켜둡니다. 인터넷 불필요)
cd mini-api
node server.js

# 터미널 2 — 앱 (위와 동일)
cd week2-start
npm run dev
```

검색이 안 되고 "API 서버가 응답하지 않습니다 (500)" 가 뜨면 **십중팔구 터미널 1이 꺼진 것**입니다.

명령어 세 개가 전부입니다.

| 명령어 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버를 켭니다 (수업 중에는 거의 이것만 씁니다) |
| `npm run build` | 배포용 파일을 `dist/` 폴더에 만듭니다 (3회차 주제) |
| `npm run preview` | 만들어진 `dist/` 를 실제 서버처럼 띄워 확인합니다 |

## "지난 주를 놓쳤어요"

괜찮습니다. 그러라고 만들어 둔 폴더입니다.

1. 이번 주가 3회차라면 `week3-start` 폴더를 통째로 **복사**합니다.
   (원본은 그대로 두세요. 다시 필요할 수 있습니다.)
2. 복사한 폴더 이름을 편한 이름으로 바꿉니다. 예: `my-vocab`
3. 그 폴더에서 `npm install` → `npm run dev`
4. 그대로 수업을 따라오시면 됩니다.

내가 만들던 코드가 망가졌을 때도 같은 방법을 쓰면 됩니다.
**고치느라 수업을 놓치는 것보다, 시작 코드에서 다시 출발하는 편이 훨씬 낫습니다.**
망가진 폴더는 지우지 말고 남겨뒀다가 쉬는 시간에 같이 봅시다.

## 자주 나는 오류

### 1. `Port 5173 is already in use`

이미 다른 터미널에서 `npm run dev` 가 돌고 있다는 뜻입니다.

- 가장 쉬운 방법: **Vite가 알아서 5174 등 다른 포트로 띄워줍니다.** 터미널에 찍힌 주소를 그대로 여세요.
- 정리하고 싶다면 이전 터미널 창에서 `Ctrl + C` 를 눌러 끕니다.
- 그래도 남아 있으면:

```bash
# macOS / Linux
lsof -ti:5173 | xargs kill

# Windows (PowerShell)
netstat -ano | findstr :5173     # 맨 오른쪽 숫자가 PID
taskkill /PID <위에서 본 PID> /F
```

### 2. `Cannot find module` / `vite: command not found`

`npm install` 을 안 했거나, **폴더를 잘못 잡고** 실행했을 때 납니다.

- `package.json` 이 있는 폴더에서 실행하고 있는지 확인하세요. (`ls` 또는 `dir`)
- `node_modules` 폴더가 없으면 `npm install` 을 먼저 실행합니다.
- 설치했는데도 이상하면 `node_modules` 폴더와 `package-lock.json` 을 지우고 다시 `npm install`.

### 3. 한글 경로 / 공백이 있는 경로

바탕화면 경로에 **한글이나 띄어쓰기, 이모지**가 있으면 일부 환경에서 설치나 실행이 실패합니다.

- 되도록 `C:\dev\my-vocab` 또는 `~/dev/my-vocab` 처럼 **영문 경로**로 복사해서 쓰세요.
- 폴더 이름도 영문 + 하이픈만 씁니다. (`나만의 단어장` ❌ / `my-vocab` ✅)

### 4. 화면에 한글이 깨져 보입니다

`index.html` 의 `<head>` 안에 `<meta charset="utf-8" />` 이 있는지 확인하세요.
이 폴더의 시작 코드에는 이미 들어 있습니다. 그래도 깨진다면 에디터가 파일을
다른 인코딩으로 저장한 경우입니다 — VS Code 오른쪽 아래에서 **UTF-8** 로 다시 저장하세요.

### 5. 화면이 하얗게 비어 있습니다

브라우저에서 **F12** 를 눌러 콘솔(Console) 탭을 여세요. 빨간 글씨에 원인이 적혀 있습니다.
대부분은 오타이거나, `import` 한 파일 경로가 틀린 경우입니다.

> **에러가 났으면 잘 하고 있는 겁니다.** 빨간 글씨를 먼저 읽어보세요. 대개 뭘 해야 하는지 적혀 있습니다.

## 폴더 구조 (week2-start 기준)

```
week2-start/
├── index.html          ← 브라우저가 제일 먼저 받는 파일. <div id="root"> 하나뿐입니다
├── package.json        ← 쓰는 라이브러리 목록 + 명령어 정의
├── vite.config.js      ← 빌드 도구 설정. `/api` 요청을 미니 API(3001)로 대신 전달하는 proxy 가 들어 있습니다 (2회차에 설명)
└── src/                ← 우리가 일하는 곳
    ├── main.jsx        ← 시작점. index.html 과 App.jsx 를 연결합니다
    ├── App.jsx         ← 앱의 최상위 화면
    ├── index.css       ← 전체 스타일 (사전 과제의 style.css 를 이어받았습니다)
    ├── data/
    │   └── words.js    ← 단어 목록 데이터
    └── components/
        ├── WordCard.jsx     ← 카드 한 장 (뒤집기 + 삭제 버튼)
        ├── WordList.jsx     ← 카드 여러 장 (.map + key)
        └── AddWordForm.jsx  ← 단어 추가 폼 (1회차 과제 결과물)
```

`week1-start` 에는 `data/` 와 `components/` 가 없습니다.
**그 두 개를 만드는 것이 1회차 실습입니다.**

> **`mini-api/` 는 구조가 다릅니다.** 여기만 React 앱이 아니라 서버입니다.
> `server.js` 하나에 전부 들어 있고 **의존성이 0개**라 `npm install` 도 필요 없습니다 —
> `node server.js` 로 바로 뜹니다.
